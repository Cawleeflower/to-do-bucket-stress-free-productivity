# ADR-013: Motivational messages are written by each user

- Status: Accepted
- Date: 2026-11-09
- Decided via Q5 (written by each user)

## Context

The Temptation Fighter (FR-11) shows motivational messages in one tap.

## Decision

Motivational messages are written by each user and synced like tasks.

## Rationale

The user's own words work better than generic quotes; no licensing or AI cost.

## Trade-off accepted

New users start with an empty list; the empty state shows how to write the first message.

## Revisit when

Users ask for shared or suggested messages.
